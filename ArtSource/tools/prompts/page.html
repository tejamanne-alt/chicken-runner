Art pipeline · ChatGPT or Gemini images → Blender → Unity

Chicken Runner Art Prompts

Prompts for the village scenes, characters, props, textures and story frames, written for ChatGPT and for Gemini. Each image has an ID, a file name and a shape, so it comes back named for the Blender scene it feeds.

How to use it with ChatGPT

  1. Make A0 first, in a new ChatGPT chat, attaching your four kid images. Then make A1, attaching A0 and your rooster photo.
  2. Stay in that chat. Each copied prompt asks ChatGPT to match A1 and carries the style rules. Attach the files under Attach; A0 is the kid reference from now on.
  3. Save each image with its file name.
  4. Put them in the repo at ArtSource/references/, or upload them here, in batches. Start with the marked first batch.

Regenerate when

Words or labels appear in the image, a model sheet is not side-on and flat, or a background that should be plain is not. Ask ChatGPT to fix just that, in the same chat.
